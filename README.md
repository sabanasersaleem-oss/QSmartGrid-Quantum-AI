### Overview
**QSmartGrid** is a hybrid **AI + Quantum Computing** prototype designed to optimize campus energy usage and promote sustainability. It integrates **AI-based forecasting (Google Vertex AI)**, **Quantum Optimization (Cirq QAOA)**, and **Generative AI (Gemini Pro)** to build an intelligent, scalable, and explainable system for smart energy management.

#### Key Capabilities:
- Predicts hourly building-level energy demand using **Vertex AI**  
- Optimizes load distribution using **Quantum QAOA circuits**  
- Generates natural-language insights and recommendations via **Gemini Pro**  
- Visualizes before/after efficiency gains through a **Streamlit dashboard**

### How to Run
1. **Open in Colab:** click the “Open in Colab” badge above ☝️  
2. Run all cells sequentially to:  
   - Generate synthetic campus energy consumption data  
   - Forecast hourly demand  
   - Apply quantum optimization (QAOA)  
   - Visualize efficiency results and recommendations  

3. (Optional) Launch dashboard:
   streamlit run dashboard.py
